# Code de conduite

Ce projet applique le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/) : respect, bienveillance et critiques portant sur le code, jamais sur les personnes. Le harcèlement et les propos discriminatoires ne sont pas tolérés.

Pour signaler un comportement, utilisez le [signalement privé](https://github.com/SimzyGit/Trait64/security/advisories/new) ou contactez le mainteneur depuis son profil GitHub. Les signalements restent confidentiels.
